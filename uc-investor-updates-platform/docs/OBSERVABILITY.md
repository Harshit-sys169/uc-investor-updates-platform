
# Observability

## What is included

- Service metric samples
- Request trace samples
- Incident records
- Alert rules
- `/observability` dashboard
- `/api/observability` JSON endpoint

## Intended integrations

- OpenTelemetry for traces
- Datadog, Grafana, or New Relic for dashboards
- Sentry or similar for error capture
- Slack/PagerDuty for incident notifications
